# InFlow

O InFlow organiza dados públicos do **Senado Federal** em PostgreSQL para analisar perfil
parlamentar, CEAPS, fornecedores, comissões, votações, presença plenária e estrutura de gabinete.

A E1 entrega a fonte transacional modelada, migrável e populada. As consultas analíticas e a
camada de consumo evoluem nas entregas seguintes.
