# Processos do Squad

Esta aba registra **como** o Mandato Aberto é construído: quem faz o quê, como o trabalho entra no
repositório e o que precisa ser verdade para uma entrega ser considerada pronta. A documentação
técnica (o **quê** e o **porquê**) fica na aba [Documentação](/docs/intro).

## Ciclo de uma entrega

1. **Leitura do enunciado.** O squad transforma o checklist de aceite em itens rastreáveis
   que compõem a definição de pronto da entrega.
2. **Divisão por domínio.** Cada frente vira uma branch própria (ex.: modelagem, ingestão, ADR,
   documentação). Domínios do banco — parlamentar, comissões, presença, CEAPS, gabinete — são
   unidades naturais de divisão, porque cada um tem job, tabelas e testes próprios.
3. **Integração contínua em `main`.** Branches pequenas, integradas por Pull Request assim que o
   item está de pé, em vez de uma grande integração no último dia.
4. **Verificação do zero.** Antes de fechar a entrega, alguém que não escreveu o código clona o
   repositório, sobe o ambiente com `docker compose` a partir de um volume vazio e roda os testes.
5. **Retrospectiva curta.** O que funcionou, o que quebrou e o que muda na próxima entrega fica
   registrado como lições aprendidas.
